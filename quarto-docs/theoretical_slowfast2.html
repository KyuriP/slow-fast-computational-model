1. Motivation

Mental health symptoms fluctuate on fast time scales (hours–days), while socio-economic pressures such as financial precarity, discrimination, or workload change more slowly (months–years). Standard symptom-network models:

  • treat symptoms as a closed system,
  • interpret group differences in network structure as internal differences.

Here we explicitly couple:

  • a fast 0/1 Curie–Weiss symptom layer (binary symptoms with mean-field interaction),
  • a slow precarity variable (\(P_t\)) that drifts gradually,
  • feedback from symptoms back into precarity.

We show how group differences in symptom trajectories can arise purely from:

  • different precarity baselines and
  • different feedback strengths,

with identical fast-layer parameters.

We examine:

  • Scenario A: Weakly nonlinear fast layer (no bistability).
  • Scenario B: Strongly nonlinear fast layer with bistability; precarity almost fixed around different baselines.
  • Scenario C1: Same bistable fast layer + strong two-way feedback → catastrophic drift into high-symptom regime.
  • Scenario C2: Same bistable fast layer + moderate feedback + noise → episodic flipping in and out of high-symptom regime.

2. Fast layer: 0/1 Curie–Weiss symptoms

We use a Curie–Weiss-type model with spins

\[ s_i \in {0, 1}. \]

The mean symptom activation is

\[ m = \frac{1}{N}\sum_i s_i \in [0,1]. \]

The local “field” for a node is

\[ H = J(m - \tfrac{1}{2}) + h_0 + \gamma_P P. \]

We then update spins with a logistic rule:

\[ \Pr(s_i = 1 \mid m, P) = \sigma\big(\beta H\big) = \frac{1}{1 + e^{-\beta H}}. \]

For large enough \(\beta J\) (specifically \(\beta J > 4\)) this mean-field system is bistable for an intermediate range of \(P\).

Code 
# One fast update block for 0/1 Curie–Weiss Ising layer
# s in {0,1}; P is current precarity
ising_fast_step01 <- function(
  P,
  s,
  beta   = 1.0,
  J      = 1.0,
  h0     = 0.0,
  gammaP = 0.5,
  sweeps = 30
){
  n <- length(s)  # spins in {0,1}
  
  for (sw in seq_len(sweeps)) {
    m <- mean(s)  # mean activation in [0,1]
    
    # field for this mean-field model
    H <- J * (m - 0.5) + h0 + gammaP * P
    p <- inv_logit(beta * H)
    
    # update spins
    for (u in seq_len(n)) {
      i    <- sample.int(n, 1)
      s[i] <- rbinom(1, 1, p)
    }
  }
  s
}

3. Slow layer: precarity dynamics

The slow variable \(P_t\) evolves with:

  • mean reversion to group-specific baseline \(P_{\text{base}}\),
  • feedback from symptoms through a slowly evolving average \(m_{\text{slow}}\),
  • Gaussian noise.

Discrete-time dynamics (Euler–Maruyama):

\[ m_{\text{slow}, t+1} = m_{\text{slow}, t} + \lambda_m (m_t - m_{\text{slow}, t}), \]

\[ P_{t+1} = P_t + dt\left[-\kappa(P_t - P_{\text{base}}) + b(m_{\text{slow}, t} - m_*)\right] + \sigma_P\sqrt{dt},\epsilon_t. \]

Code 
simulate_slowfast_cw01 <- function(
  T_steps = 4000,
  dt      = 0.02,
  P_base  = 0,
  P0      = 0,
  m0      = 0.1,     # initial mean in [0,1]
  kappa   = 0.2,
  b       = 0.3,
  m_star  = 0.3,
  sigmaP  = 0.03,
  lambda_m = 0.003,
  # fast layer params
  n_nodes = 100,
  sweeps  = 30,
  beta    = 1.0,
  J       = 1.0,
  h0      = 0.0,
  gammaP  = 0.5,
  seed    = 1
){
  set.seed(seed)
  
  P      <- numeric(T_steps)
  m_fast <- numeric(T_steps)
  m_slow <- numeric(T_steps)
  
  P[1]      <- P0
  m_fast[1] <- m0
  m_slow[1] <- m0
  
  # initial spins in {0,1}
  s <- rbinom(n_nodes, 1, m0)
  
  for (t in 1:(T_steps - 1)) {
    # --- fast update ---
    s <- ising_fast_step01(
      P      = P[t],
      s      = s,
      beta   = beta,
      J      = J,
      h0     = h0,
      gammaP = gammaP,
      sweeps = sweeps
    )
    
    m_fast[t] <- mean(s)
    
    # --- slow moving average of symptoms ---
    m_slow[t+1] <- m_slow[t] + lambda_m * (m_fast[t] - m_slow[t])
    
    # --- slow precarity drift ---
    drift <- -kappa * (P[t] - P_base) + b * (m_slow[t] - m_star)
    P[t+1] <- P[t] + dt * drift + rnorm(1, 0, sigmaP * sqrt(dt))
  }
  
  # final fast snapshot for plotting
  m_fast[T_steps] <- m_fast[T_steps - 1]
  
  tibble(
    t      = 1:T_steps,
    P      = P,
    m      = m_fast,
    m_slow = m_slow
  )
}

4. Mean-field bifurcation of the 0/1 Curie–Weiss layer

For 0/1 spins, the mean-field fixed point satisfies:

\[ m = \sigma\left(\beta\left[J(m - \tfrac{1}{2}) + h_0 + \gamma_P P\right]\right). \]

We solve this numerically and classify stability via

\[ \frac{df}{dm} = \beta J \sigma(H)\big(1 - \sigma(H)\big) - 1, \quad H = J(m - 1/2) + h_0 + \gamma_P P. \]

Code 
cw01_fixed_points <- function(P, beta, J, h0, gammaP){
  f <- function(m) inv_logit(beta * (J*(m - 0.5) + h0 + gammaP*P)) - m
  
  df <- function(m){
    p <- inv_logit(beta * (J*(m - 0.5) + h0 + gammaP*P))
    beta * J * p * (1 - p) - 1
  }
  
  grid <- seq(0, 1, length.out = 801)
  vals <- f(grid)
  idx  <- which(diff(sign(vals)) != 0)
  
  roots <- c()
  for (k in idx) {
    r <- try(uniroot(f, c(grid[k], grid[k+1]))$root, silent = TRUE)
    if (!inherits(r, "try-error")) roots <- c(roots, r)
  }
  roots <- sort(unique(round(roots, 6)))
  if (!length(roots)) return(NULL)
  
  tibble(
    P      = P,
    m      = roots,
    stable = df(roots) < 0
  )
}

cw01_bifurcation_curve <- function(P_grid, beta, J, h0, gammaP){
  map_dfr(P_grid, ~ cw01_fixed_points(.x, beta, J, h0, gammaP))
}

5. Parallel helper: simulate low vs high groups

Code 
run_scenario_parallel <- function(
  par_fast,
  par_slow,
  P_bases,
  labels,
  T_steps,
  seeds
){
  stopifnot(length(P_bases) == length(labels),
            length(labels)  == length(seeds))
  
  param_list <- pmap(
    list(P_base = P_bases,
         label  = labels,
         seed   = seeds),
    function(P_base, label, seed){
      list(
        args = c(
          list(
            T_steps = T_steps,
            P_base  = P_base,
            P0      = P_base,
            m0      = 0.1,
            seed    = seed
          ),
          par_fast,
          par_slow
        ),
        meta = list(group = label)
      )
    }
  )
  
  sim_list <- future_map(
    param_list,
    function(cfg){
      out <- do.call(simulate_slowfast_cw01, cfg$args)
      out$group <- cfg$meta$group
      out
    },
    .progress = FALSE
  )
  
  bind_rows(sim_list)
}

6. Scenario A – Weakly nonlinear, no bistability

  • Parameter setting:

    • Fast layer: low coupling → βJ < 4 → no bistability.

    • Slow layer: moderate mean reversion.

    • Groups only differ in \(P_{base}\).

  • Mechanics: The Curie–Weiss activation function is shallow and unimodal. For any value of precarity \(P_t\), the fast layer quickly relaxes to a single equilibrium \(m^*(P)\).

Thus:

\[ P_{\text{low}} < P_{\text{high}} \quad\Rightarrow\quad m_{\text{low}} < m_{\text{high}}, \]

but the relationship is nearly linear and weak.

7. Scenario B – Bistable fast layer, P almost fixed

  • Parameter setting:

    • Fast layer: βJ > 4 → bistability (two stable symptom equilibria).
    • Slow layer: strong mean reversion (\(κ\) large) → \(P\) remains near its baseline.
    • Groups differ only in \(P_{\text{base}}\).

  • Mechanics: Because the fast layer is bistable, the bifurcation diagram contains two stable branches:

    • low-symptom attractor \(m_{\text{low}}(P)\)
    • high-symptom attractor \(m_{\text{high}}(P)\)

If a group’s baseline precarity lies:

  • below the bistable window → they fall into the low-m basin
  • above the bistable window → they fall into the high-m basin

But because \(κ\) is large, each group’s \(P_t\) barely moves from its baseline — they remain “locked” on their respective branches.

    • No switching or noise-driven episodes.
    • A clean demonstration of structural separation due to slow baselines.

8. Scenario C – Bistability + strong two-way feedback

We keep the same bistable fast layer (par_fast_B) but weaken mean reversion and/or increase feedback and noise so that \(P_t\) can wander through the bistable region.

We consider:

  • C1: Catastrophic drift into high-symptom regime.
  • C2: Episodic flipping in and out of the high-symptom basin.

8.1 Scenario C1 – Catastrophic flip

  • Parameter setting:

    • Same bistable fast layer as Scenario B.

    • Slow layer:

      • weak mean reversion (\(κ\) small)
      • strong symptom feedback (\(b\) large)
      • low noise

  • Mechanics:

    Here \(P_t\) can drift far from \(P_{\text{base}}\). If symptoms rise slightly, strong feedback pushes precarity upward:

\[ m_{\text{slow}} \uparrow \quad\Rightarrow\quad P \uparrow. \]

This, in turn, shifts the fast layer’s field upward, which increases m — creating a positive feedback loop.

If \(P\) crosses the upper fold of the bifurcation diagram, the low-m state disappears and the system collapses into the high-symptom branch (“catastrophe”).

8.2 Scenario C2 – Episodic flips up and down

*Parameter setting:

  • (moderate κ, moderate b, higher noise → stochastic switching)

  • Same bistable fast layer.

  • Slow layer:

    • weaker positive feedback,
    • stronger mean reversion,
    • higher noise σₚ.

  • Mechanics:

\(P\) fluctuates near the bistable region, occasionally being nudged above or below fold points by noise. Crossing a fold forces the system into the opposite symptom branch:

\[ \text{cross lower fold} \Rightarrow m_{\text{high}} \to m_{\text{low}} \] \[ \text{cross upper fold} \Rightarrow m_{\text{low}} \to m_{\text{high}} \]

Because \(κ\) is stronger here, P often drifts back, allowing repeated entries and exits from the high-symptom basin.

  switch(
    scenario,
    "A" = list(
      par_fast = par_fast_A,
      par_slow = par_slow_A,
      P_bases  = P_bases_A,
      labels   = labels_2,
      T_steps  = 6000

      P_bases  = P_bases_B,
      labels   = labels_2,
      T_steps  = 6000

      P_bases  = P_bases_C1,

simulate_replicates <- function(scenario, n_rep = 10, seed_base = 1000){
  cfg <- scenario_config(scenario)
  
  rep_list <- furrr::future_map(
    1:n_rep,
    function(r){
      seeds <- seed_base + c(2*r, 2*r + 1)
      out <- run_scenario_parallel(
        par_fast = cfg$par_fast,
        par_slow = cfg$par_slow,
        P_bases  = cfg$P_bases,
        labels   = cfg$labels,
        T_steps  = cfg$T_steps,
        seeds    = seeds
      )
      out$rep <- r
      out
    },
    .progress = FALSE
  )
  
  bind_rows(rep_list) %>% mutate(scenario = scenario)
}

  • Interpretation:

    • The system shows episodes of high symptoms but does not remain stuck.
    • High-precarity groups show greater volatility and more switching.
    • This scenario is closest to describing episodic depression / relapses driven by social stress variability.

  • Simulation output:

    • Low group stable at low m.
    • High group fluctuates, producing intermittent spikes of high symptoms.
    • Both m and P show characteristic “plateau–jump–plateau” dynamics.

This scenario provides an interpretable mechanistic explanation for instability in high-precarity populations.

12. HELIUS Application — Data-Driven Calibration of the Curie–Weiss Slow–Fast Model

This section demonstrates how group differences in HELIUS symptoms (e.g., Dutch vs non-Dutch) can be reproduced using the data-calibrated Curie–Weiss slow–fast model.

We proceed in four steps:

  1. Clean HELIUS and construct:
    • a precarity index \(zP\)
    • binary symptoms for the fast layer
  2. Estimate Curie–Weiss parameters from the symptom covariance:
    • effective slope \(\beta J\)
    • external field offset \(h_0\)
  3. Place empirical group means onto the empirical bifurcation diagram
  4. Calibrate the slow layer so that the simulated ΔP and Δm
    match HELIUS ΔP and Δm.

Primary demonstration: Ethnicity (Dutch vs NonDutch)
Other groupings (Education, Gender, Age) can be swapped with a single line.

12.5 Estimate fast-layer Curie–Weiss parameters from HELIUS

We treat HELIUS symptom correlations as arising from a mean-field CW model:

\[ m = \sigma\big(\beta[J(m - 1/2) + h_0 + \gamma_P P]\big) \]

Data identify:

  • slope near mean → \(\beta J\)
  • intercept → \(h_0^\text{eff}\)

12.5.1 Compute empirical correlation matrix

12.7 Calibrate the slow layer using HELIUS ΔP and Δm**

We want:

\[ |\Delta m|_{\text{sim}} \approx |\Delta m|_{\text{emp}}, \quad |\Delta P|_{\text{sim}} \approx |\Delta P|_{\text{emp}}. \]

We will set:

  • baseline \(P_\text{base}\) = empirical means
  • \(b, \kappa, \sigma_P\) tuned to approximate empirical contrast
  • \(m_* =\) empirical global baseline
# Fast layer calibrated from HELIUS:

par_fast_H <- list(
n_nodes = 100,
sweeps  = 40,
beta    = beta_H,
J       = J_H,
h0      = h0_H,
gammaP  = gammaP_H
)

# Global m baseline = empirical mean

m_star_H <- mean(rowMeans(sym_mat))

# Slow layer calibration:

# Rough moment-matching: Var(P) ~ sigmaP^2 / (2*kappa)

# Want Var(zP) ≈ 1 → choose kappa ~0.3 → sigmaP ≈ sqrt(2*0.3)

kappa_H  <- 0.30
sigmaP_H <- sqrt(2 * kappa_H)   # ~ 0.775
b_H      <- 0.20                # moderate symptom → P feedback

par_slow_H <- list(
dt       = 0.02,
kappa    = kappa_H,

m_star   = m_star_H,
